## Expected Screenshots & Filenames

To add your actual application screenshots:

| Filename | Component / Screen to Capture |
| :--- | :--- |
| **`dashboard.png`** | Full view of the application results after loading a dataset (Header, Top Findings, and Overview). |
| **`data-quality.png`** | The **Data Overview** section showing the Quality Score (0–100), metric pills, and column profiles. |
| **`prediction-studio.png`** | The **Prediction Studio** section showing target column selection, model confidence, and the Key Drivers chart. |
| **`business-insights.png`** | The **Key Business Insights** and **Business Recommendations** cards. |

---

## How to Add Screenshots Directly on GitHub

1. Open this folder in your browser: `https://github.com/HARIHRITHIK/ai-business-intelligence-studio/tree/main/assets/screenshots`
2. Click **Add file** $\rightarrow$ **Upload files**.
3. Drag and drop your screenshots using the **exact filenames** listed above (`dashboard.png`, `data-quality.png`, `prediction-studio.png`, `business-insights.png`).
4. Commit changes to `main`.
5. The screenshots will automatically render in the main repository `README.md`.
